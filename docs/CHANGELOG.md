# HIVE 更新日志

## 0.1.9 · 2026-11-26

- 本地服务迁移到 C#，覆盖文稿、仓库、模型和 AI 工具、模板和插件、界面偏好及更新。
- Windows 目录包内置 .NET 运行时。现有桌面资料目录、文稿格式和编辑窗口流程继续适用。
- 从 0.1.8 升级时使用完整目录包。0.1.9 的目录版更新包同时包含前端和 C# 后端资源。

## 0.1.8 · 2026-11-23

- 回收站支持在正文标签页只读预览 Markdown。顶栏增加最近仓库菜单。
- 可从正文标签页和整表选区将文稿或表格作为附件交给 AI。对话顶部显示实际操作目标，回复支持撤回和分支。
- 润色结果可在原文下方独立预览、继续批注或手改后采纳。撤回采纳会恢复原文和对照框。
- 可排列对话功能按钮，设置 AI 回复的详细度、语气、自定义规则和人设。写作区底栏新增叙述／对话比例及平均段长。
- 默认模板保留「地中海蓝」和「青苔鎏金」，旧用户的个人模板和配色资料继续保留。

## 0.1.7 · 2026-11-21

- Windows 目录版可在关于页切换本地来源和 GitHub 稳定版更新，保存所选来源，并在下载后校验更新包。
- 点击原表头或吸顶表头的「选择整张表格」，在正文中选中含表头及全部数据行的 Markdown。选择表格时保留当前 AI 输入草稿。
- 拖动模型推理强度滑条时，档位标签和轨道随滑块同步。可见刻度使用白色，彩色轨道带有缓慢流动的高光，边缘发光随档位增强。
- 回收站的排序菜单保留按删除时间和按名称的两种方向。每个条目仍显示原位置。

## 0.1.6-r4 模板图标包 · 2026-11-20

- 将主界面、编辑器控件和原生停靠提示接入同一套图标定义。临时图标包集中在 `templates/icons.json`，包含 178 个图标键，其中 51 枚来自定稿 SVG。 [模板图标包](../templates/icons.json) · [定稿图标键](../scripts/approved-icon-ids.json)

- 可从「设置 → 外观 → 管理」打开模板目录，按图标键替换整套或部分图标。切换模板或保存图标包后，已显示的图标会自动更新。 [模板说明](../templates/README.md)
- 图标包被删除、缺少某个图标或包含无效定义时，对应图标逐层回退，最终使用随程序发布的内置图标。损坏的包会在外观设置里提示，程序可以继续启动和操作。
- r4 全量 1,019 项测试通过，源码版和 Windows 打包版各通过 16 项隔离桌面图标检查，打包版另通过 48 项应用联动检查。真实鼠标拖拽待实测。

## 0.1.6-r1 核心编辑与渲染

- 修复长代码行横向滚动后右端的光标定位和编辑。拖选格式化正文时，保留开始拖动时的排版，避免选区漂移（01/02 · BUG-055/056）。
- 显示模式新增只读的「实时预览」，仍可单击链接打开目标文件。「实时编辑」沿用原有的渲染编辑和撤销历史，菜单中的「代码模式」名称同步简化。同一文稿的其他标签或磁盘更新仍会同步到预览（03/04 · BUG-038）。
- 点击表格文字时在对应位置进入单元格编辑，可在单格内选字、修改和撤销（05 · BUG-037）。
- 分栏滚动以可见的源码位置为基准对齐对应标题和段落，栏宽变化后重新测量，保留目录和查找触发的跳转位置（06 · BUG-065）。
- 通过拖动分隔线或按方向键调整两栏宽度（07 · REQ-037）。
- 在「设置 → 界面」切换源码和语义栏的左右位置（08 · REQ-040）。
- 单击仓库文件链接在新标签页打开，悬停时以主题色变化提示可点击（09/10 · BUG-036）。
- 「跳转至文件」使用与同级菜单一致的图标、文字和行高。点击右键菜单外部时关闭菜单（11/17 · BUG-035/057）。
- 渲染与中文相邻的引号加粗，保留引号。多级列表逐级缩进，换行与条目正文起点对齐（12/13 · BUG-060/066）。
- 宽表根据每列多数单元格的内容分配宽度。少数长内容在列内换行，手工拖出的列宽优先。宽表支持局部横向滚动，吸顶表头随横移对齐对应列，离开表格时解除。列选择圆钮完整显示（14/15/16 · BUG-059/039/040）。

## 0.1.6 会话与保存

- 文档标签直接使用当前会话的编辑状态、文件路径和未保存状态，切换标签或窗口时减少重复同步。
- 正文已经写入、文件时间记录更新失败时，保留保存结果并提示时间记录问题。保存期间继续编辑的内容仍标记为未保存。
- 同步模型选择提示与长方案名布局。无推理档位的模型只报模型名，外观设置中的长方案名右对齐并允许换行。

## 0.1.5 模型输入与聊天框图标

- 底部聊天框左下角改为模型图标，图标右侧的四根短柱显示当前推理档位；点击即可打开模型选择面板。模型未声明档位时只显示图标。
- 服务默认强度直接按最高档显示（轨道填满、粒子尾迹可见）；点「服务默认」按钮取消默认后，滑块回到初始档，再由低到高手动调整。
- 聊天头部不再重复显示当前模式文字，写作模式由图标栏承担；「依据」改为带书本图标的按钮，悬停与键盘焦点都有反馈。
- 「设置 → 外观 → 输入框阴影」可单独调整 AI 栏输入框的阴影颜色、模糊半径与垂直偏移，并提供预览和恢复默认。该阴影只作用于 AI 栏，面板、弹层与主聊天页不受影响。
- 从上游导入模型或更换接口地址后，若上游没有声明推理档位，默认启用 low / medium / high / max 四档；上游已声明的档位照旧，用户手动取消全部档位后不再自动回填。
- 模型设置新增「输入类型」文本 / 图片勾选，并从上游的输入模态自动带入。发送含图片的消息时，若当前模型未声明图片输入，会在请求前拒绝并提示去模型设置勾选。
- 回收站改为三级结构：面板标题下是一行工具（搜索、保留期限、排序图标、清理图标），列表行在悬停或聚焦时显示恢复与永久删除。新增按条目删除接口，支持单个和批量永久删除，确认框仍保留原位置信息。
- 修正设置弹层滚到中段后点关闭时「放弃这次尚未保存的编辑？」出现在视口外、看不到确认提示的问题；现在会自动滚到提示处。
- 修正外观「当前方案」的长模板名被压成竖排单字的问题，名称改为单行右对齐，必要时换行。

- 文档列表为空时，将「打开仓库管理」居中显示。很矮的面板将搜索和文件操作排在一行，为按钮留出空间。
- 上游模型选择弹层将「已选 N / 100」移到底部左侧，精简搜索框下方的说明。
- 顶栏仓库入口增加文件夹图标、边框、底色和悬停反馈。长仓库名按可用宽度省略，键盘可见焦点使用主题强调色。
- 顶栏两端留白对称，分隔线统一线宽、高度和相邻控件间距，随界面缩放调整。
- 写作大纲和标题目录采用一致的字号层级，并保留 10 CSS px 的字号下限。
- 推理强度的「服务默认」改为文字按钮。选中时以无进度填充的轨道表示由服务决定。
- 提高黑色方案下推理轨道、档位圆点和滑块对比度。「关闭」档的轨道不显示渐变进度。
- 推理滑条粒子默认为白色，保留档位自定义颜色和减少动态效果设置。
- 底部 AI 按钮在生成期间显示流光。启用减少动态效果时，以静态高光提示生成状态。

- 编辑 AI 服务的弹层顶部栏改用标签栏表面色，与下方表单卡片区分开。

## 0.1.5 草稿删除与发送键

- 文档树可以把「自由草稿.md」删除到回收站，与其它文稿一致；删除后草稿面板显示为空，下次保存重建该文件。改名和移动仍由草稿面板管理。
- 删除或移动被拒绝时，确认框不再停在原地反复失败：提示改为面板内的提示条，关闭后从菜单重试。
- AI 输入框改为「Enter 发送、Shift+Enter 换行」，`Ctrl/Cmd+Enter` 继续可用；中文输入法回车选词不会误发。

## 0.1.5 模型设置与推理滑条

- 添加或编辑 AI 服务时，底部保存按钮使用主题主色，取消按钮使用描边，两个按钮的点击区扩大到 42 × 38 CSS px。
- AI 栏推理滑条的轨道从 12 加厚至 14 CSS px，滑块尺寸和悬停放大保持原有表现。
- 在「设置 → 外观」可分别设置推理轨道的左、中、右三色。配色按模板和基础颜色保存，档位变化只裁切全长渐变。
- 从手动档位切回服务默认时，档位圆点从右向左依次淡出。启用「减少动态效果」时直接隐藏圆点。

## 0.1.5 AI 推理条

- 服务默认按钮移到推理强度标题右侧，改用星光图标。选中后进度条显示满格，隐藏档位圆点，生成请求仍使用服务默认强度。
- 移除推理条下方的档位文字。手动选择时保留档位圆点，当前档位显示在标题中。
- 粒子尾迹从右向左流动，档位越高越快，继续使用主题配置的颜色。系统启用「减少动态效果」时隐藏尾迹。
- 圆形滑块高于轨道，指针悬停在滑块上时放大约 15%。

## 0.1.5 模型设置布局调整

- 「从接口地址填入服务名称」图标的悬停提示只显示一次。
- 服务名称和接口地址的输入框在同一行对齐。
- 获取模型弹窗右下角的按钮改为「应用」。
- 模型高级设置中的显示名称、上下文窗口和最大输出对齐，信息图标与标签同行。
- 新建或编辑 AI 服务时，取消和保存图标移到弹窗底部右侧的固定操作栏。

## 0.1.5 启动配色

- 桌面版启动时先应用上次保存的配色，再显示窗口和写作空间加载页。旧配置缺少配色时会短暂等待本地模板，读取过慢时使用可用的默认配色打开。

## 0.1.5 工作区对话修复

- 同一写作空间内，切换文稿或关闭最后一个标签页后，对话记录及未发送草稿仍在。没有打开正文时也可以讨论。
- 关闭含待审建议的文稿后，仍可从对话的「审阅建议」或原文件入口回到预览。建议保持未保存，采纳、撤掉和范围校验仍在原正文执行。
- 正在进行的讨论可以继续回复。生成正文建议时，切换标签会取消该次生成，避免把结果放进另一篇稿件。

## 0.1.5 内存与同步优化

- 仓库目录快照共用缓存和更新任务，未变化的同步响应省略整棵目录树；手动刷新、外部文件变化和低频校验更新快照。
- 扫描跳过依赖与本工程生成目录，按固定批次处理文件属性，限制驻留索引和监听数量。仓库切换后释放旧索引资源。
- 文稿同步使用有界属性/哈希提示，减少未变化正文的重复读取，保留定期内容核验及保存前完整冲突检查。
- 创建时间状态复用有限缓存，磁盘元数据被移动、恢复或替换后重新读取；失败时丢弃未提交缓存。
- 文件列表复用排序、筛选与路径索引；同步按请求完成后调度，仓库切换和手动刷新使迟到结果失效。
- 主题按样式表复用编译结果，浮窗增量镜像样式，退出时回收监听、动画帧与镜像节点。
- 从 0.1.4 独立整理源码，移除历史交付副本、旧发布产物和临时诊断脚本，开发与日用资料使用独立目录。

## 0.1.4 整合构建

本节记录统一主工程中的 0.1.4 整合内容。正在运行的版本、构建编号、渠道和时间请查看“设置 → 关于”；历史独立工作组包不代表当前主工程的全部成果。

- 表格移除常驻顶部按钮栏，改用右侧/下方悬停添加、行列选择与右键删除；普通矩形选择、行内 Markdown 预览、长格完整显示及分栏逐行对应同步修复。
- 标题旁增加章节折叠，分栏两侧同步；引用竖线移近文字。代码块保留换行并支持 Shift + 滚轮横移，接入常见已支持语言的实时语法着色；长技术字符串可提前折行。
- 当前行和输入光标提高可见度，链接增加独立文字色和仓库文件右键跳转。桌面文件定位改为原生资源管理器调用。
- 文件树避免逐个检查非 Markdown 文件，并限制并发扫描；删除成功后撤离对应正文会话，避免错误保留为未命名稿并反复要求保存。
- 新增“设置 → 关于”：展示版本、构建、渠道和运行环境，内嵌离线帮助、更新日志及许可证；诊断先预览后复制，桌面支持打开应用数据目录。没有在线更新服务。
- 仓库管理成为独立面板，支持多个已有目录、备注名称、排序和切换；桌面添加仓库使用系统目录选择，取消不会写入登记。
- 文档面板支持文件夹折叠、排序及方向切换、多选与右键批量操作；回收站位于左下方，图片详情从更多菜单打开。批量动作逐项反馈结果，异步操作继续检查文稿与 AI 提案状态。
- 正文支持 Obsidian 图片引用、标准相对图片及引用式图片；待办可写回，新增共享文稿及撤销历史的左右分栏显示。表格快捷工具支持局部插删行列并保留相关格式与标注。
- 代码模式左侧显示逻辑行号；分栏源码跟随正文视觉断行，宽度超出时可横向滚动。显示层对齐不写入文稿，退出分栏恢复阅读排版。
- 中英文混排的普通自动折行尽量两端对齐，长网址、路径和极长英文串单独处理，普通英文词保留自然字距；左对齐命令明确保存选择。
- 文字颜色可手动调整，个人配色按模板与基础色隔离；停靠引导、落位预览和拖放提示采用共享主题配置。
- 外观设置新增“文本编辑页面”，集中调整页面背景、正文文字和 12 项编辑区颜色，其中 8 项高亮背景支持透明度；文本选区颜色独立于全局选中项目背景。
- 窗口生命周期集中处理浮动、收纳、回接与故障恢复；原生几何使用内容区域和缩放换算，避免反复开关引起尺寸与位置累积变化。

真实鼠标、中文输入法、跨屏与实际模型效果仍需按具体整合构建验收；源码和自动化检查不等同于这些操作已经完成。
